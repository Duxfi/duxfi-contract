# Security Policy

## Project Type

**This is a testnet DeFi simulation project** running on the Sepolia test network. It is designed for educational purposes and does not involve real assets or actual financial value.

## Testnet Disclaimer

- All tokens are test tokens with no real value
- No real funds are involved
- This project is intended for learning and testing DeFi concepts safely

## Reporting a Vulnerability

For security vulnerabilities or concerns:

1. **Do NOT** create a public GitHub issue for security issues
2. Send a [Private Vulnerability Report](https://github.com/duxfi/dux-swap-contracts/security/advisories/new) instead
3. Or contact the team via the official DuxFi channels

## Security Considerations

While this is a testnet project, we still follow security best practices:

- Reentrancy guards on critical functions
- Access control with role-based permissions
- Pausable functionality for emergency stops
- Comprehensive test coverage
- Code follows OpenZeppelin security standards

## Supported Versions

| Version | Status | Network |
|---------|--------|---------|
| main | Active | Sepolia Testnet |
| development | Active | Local Anvil |

## Audits

This project has not undergone formal third-party security audits as it operates on a testnet without real asset risk. Users are encouraged to:

- Review the source code
- Conduct their own security assessment
- Report any issues through private disclosure
